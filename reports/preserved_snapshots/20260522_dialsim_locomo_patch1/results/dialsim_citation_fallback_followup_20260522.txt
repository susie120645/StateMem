5. Which new path actually helped

Important finding:
- The citation-backed fallback did not directly create any Wrong -> Correct cases in this full run.
- It applied 4 times, and all 4 were still wrong after application.
- So the restored 272/784 should not be attributed to citation_backed_choice_fallback.

What appears to matter more:
- The new zero_score_non_exact_option_match guard reduced contrastive overrides from 94 to 88.
- At least one newly blocked case was:
  - S05E12 Chandlers Work Laugh.txt / session 5
  - previous rerun path would have allowed a risky score=0, overlap<1 style abstain flip
- More generally, the patch makes the contrastive verifier less willing to trust zero-score partial lexical matches.

6. Current recommendation

Keep:
- the zero_score_non_exact_option_match guard

Revisit:
- citation_backed_choice_fallback, especially the easy_qs_ans_w_time branch

Reason:
- it produced no direct gains in this run
- it changed 4 abstentions into 4 wrong non-abstain answers

Most likely next cleanup:
- narrow or remove the easy_qs_ans_w_time citation fallback
- keep only the hard_qs_past / entity_time_lookup path if later targeted experiments show real benefit
